# austincofran.com

Personal portfolio site for Austin Cofran. Plain HTML, no build step.

- `index.html`: the whole site (styles and script inline)
- `assets/photos/<section>/`: web-ready photos (900px and 1800px WebP), sorted into portraits, couples, sports, brand, personal

Deploy: Cloudflare Pages, connected to this repo (framework preset "None", build command empty, output directory `/`).
